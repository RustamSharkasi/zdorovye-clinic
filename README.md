# «Клиника Здоровье» — сайт семейной стоматологии (концепт)

Концепт-проект для портфолио: лендинг стоматологической клиники полного цикла.
Клиника, врачи, цены и отзывы вымышлены; фотографии намеренно размыты; формы ничего не отправляют, внешние ссылки и звонки отключены (вместо перехода — уведомление «демо-версия»).

## Стек
Ванильный, без сборки: `index.html` + `css/style.css` + `js/main.js` + `assets/`.
Шрифты — Golos Text и Days One (Google Fonts). Мобайл-фёрст.

## Локальный запуск
```bash
python -m http.server 5173
# открыть http://127.0.0.1:5173
```

## Что внутри
- Hero со «сценой логотипа»: SVG-знак всплывает из воды, круги-рябь, прилив внутри знака, блик, наклон за курсором; фон — canvas-каустика.
- Услуги (bento с ценами), имплантация + квиз-калькулятор (3 шага, назад, маска телефона, валидация).
- «Почему мы», врачи, работы «до/после» (SVG-иллюстрации + слайдер-сравнение, фильтр), этапы лечения, безопасность, прайс, отзывы, FAQ, запись, контакты со стилизованной картой.
- Демо-тост вместо внешних переходов, подсветка текущего раздела в меню, липкая панель действий на телефоне, `prefers-reduced-motion`.

## Структура
- `index.html` — страница.
- `css/style.css` — дизайн-система и компоненты.
- `js/main.js` — меню, квиз, формы, слайдеры, фильтр, демо-заглушки, анимации hero.
- `assets/img/` — размытые фото, фавиконки, OG-картинка.
- `PRODUCT.md` / `DESIGN.md` — продуктовая и дизайн-документация.
